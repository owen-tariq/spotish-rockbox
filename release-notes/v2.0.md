## Spotish v2.0: Now Playing goes phone style

Now Playing is redesigned after Spotify's phone player:

- The whole screen glows in the album's own colours, with the rounded cover on top.
- *PLAYING FROM ALBUM* and the album name, then the big bold title, the artist, and a star that turns green when the song is rated.
- A thin full-width progress line with elapsed time and time remaining.
- Shuffle, previous, play/pause, next and repeat in plain white. Shuffle and repeat turn green with a dot when on.
- Turning the click wheel shows a speaker and the volume level under the line.
- The Song card, green button, add, download and more icons, and *Next in queue* are gone.

### New: album colours

Run `make_backdrops.py` (in this zip) once with the iPod connected:

```
pip install pillow mutagen
python make_backdrops.py
```

It makes a `cover.320x240.bmp` glow picture for every album, and Spotish picks them up automatically. Run it again after adding music. See `ALBUM-COLOURS.md` in the zip.

The theme now sets `album art: prefer image file`, so these pictures are used before art embedded in the songs.

### Install

Copy the zip's `.rockbox` folder onto the iPod, merging it with the existing one. Then choose **Settings → Theme Settings → Browse Theme Files → Spotish**.

Both skins are checked with Rockbox's own parser (`checkwps`, iPod Video target) on every build.
